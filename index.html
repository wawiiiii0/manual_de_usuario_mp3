Sección 1.3

Introducción y prerrequisitos

Gracias por adquirir este reproductor de audio digital (MP3). Este manual explica cómo configurarlo, operarlo día a día y resolver los problemas más comunes.

Precauciones antes de usar

  • No intente abrir, reparar o modificar el producto por su cuenta.
  • No use el equipo en zonas donde esté prohibido el uso de dispositivos electrónicos.
  • No introduzca el producto ni sus accesorios en la boca.
  • No sumerja el producto en agua u otros líquidos.
  • No deje caer el equipo ni sus accesorios.
  • No exponga el equipo a luz o calor excesivos, para prolongar su vida útil.
  • Cargue por completo la batería (litio integrada) antes de un período prolongado sin uso.
  • Conecte y desconecte los cables de audífonos y USB con cuidado.

Prerrequisitos para empezar

Cargador / USB
Salida de 5V, 500–1000 mA, o un cable Micro USB a un puerto USB2.0.
Tarjeta Micro SD (opcional)
Compatible con Micro SD / MMC / SDHC, para ampliar el almacenamiento.
Audífonos
Con conector estándar, para escuchar música, radio FM o grabaciones.
Computadora
Con puerto USB2.0, para cargar archivos de música, video, fotos o libros.
Herramienta de conversión de video
Incluida en el CD-ROM del equipo, necesaria para convertir videos al formato compatible.

Sección 2.2

Guías paso a paso

Encender y apagar el equipo
  1. Para encender: mantenga presionado el botón ⏻/🔒 durante 3 segundos.
  2. Para apagar: mantenga presionado el mismo botón ⏻/🔒 durante 3 segundos.
  3. Para cargar la batería, conecte el cable Micro USB a un cargador con salida 5V, 500–1000 mA. El equipo puede grabar audio con normalidad mientras se carga.
  4. Puede usar un "power bank" para extender el tiempo de uso; presione el botón de Menú para salir del modo de conexión de carga.
Reproducir música
  1. Desde el menú principal, seleccione el icono de Música.
  2. Presione el botón Reproducir/Pausar (▶) para iniciar la reproducción; vuelva a presionarlo para pausar o reanudar.
  3. Ajuste el volumen con toques cortos en ＋ o －.
  4. Mantenga presionado el botón Siguiente o Anterior para avanzar o retroceder rápidamente dentro de la canción.
  5. Con toques cortos en Siguiente/Anterior cambia de pista.
  6. Para ajustar la configuración de reproducción (EQ, repetición, etc.): presione el botón de Menú, use ＋/－ para moverse entre opciones, confirme con el botón Reproducir y regrese con el botón Regresar.
Usar la radio FM
  1. Entre al modo Radio FM desde el menú principal.
  2. Presione el botón de Menú para acceder a la configuración: emisoras preestablecidas o sintonización manual/automática.
  3. Use ＋/－ para buscar la frecuencia deseada.
  4. Confirme con el botón Reproducir. La operación de escucha es igual a la de música.
Conectar por Bluetooth
  1. Seleccione el icono Bluetooth en el menú principal.
  2. Elija "Control de Bluetooth" y confirme "Bluetooth Abierto/ON".
  3. Seleccione "Buscar dispositivo" para localizar y emparejar el dispositivo deseado.
  4. Una vez conectado, el ícono de Bluetooth en la parte superior de la pantalla se pondrá azul.
  5. Algunos dispositivos pueden solicitar un código PIN; consulte al proveedor del dispositivo si es necesario.
Grabar voz
  1. Presione el botón Reproducir para entrar al modo de grabación de voz.
  2. Seleccione "Iniciar grabación" y confirme con el botón Reproducir.
  3. Puede revisar y ajustar otros parámetros de grabación disponibles antes o después de grabar.
Herramientas: calendario, cronómetro, alarma y FM programado
  1. Calendario: toque corto en el botón de Menú para cambiar de campo; toque corto en Siguiente/Anterior para ajustar el valor.
  2. Cronómetro: toque corto en Reproducir para iniciar el conteo; vuelva a tocar para pausar. Use Siguiente/Anterior para iniciar un segundo y tercer temporizador (hasta 5 en total). Toque el botón de Menú para detener y borrar, y Regresar para salir.
  3. Alarma: configure encendido/apagado, hora, ciclo, música y volumen de la alarma.
  4. FM programado: funciona como una alarma que reproduce radio FM. Configure encendido/apagado, hora de inicio y fin, ciclo, banda de FM, volumen y si desea grabar automáticamente.
Configurar el sistema
  1. Ingrese a "Configuración del sistema" desde el menú principal.
  2. Ajuste reproducción, sonido, apagado automático, pantalla (brillo, retroiluminación, protector), fecha y hora, idioma y presentación de diapositivas.
  3. Consulte "Info" para ver el modelo, versión de software/hardware y espacio disponible en disco.
  4. Use "Formatear dispositivo" para borrar el disco principal o la tarjeta externa.
  5. Use "Configuración de fábrica" para restaurar los valores originales.

Sección 2.3

Reglas de negocio — límites, parámetros y condiciones del sistema

Estas son las reglas y rangos que gobiernan el comportamiento del equipo. Respetarlas evita errores de uso y asegura el funcionamiento correcto de cada función.

ParámetroRegla / Rango permitido
Apagado automáticoConfigurable de 1 a 99 minutos, en pasos de 1 minuto.
Brillo de pantallaRango de 0 a 11 (valor por defecto: 5).
Tiempo de retroiluminaciónOpciones fijas: 10s, 20s, 30s o siempre encendida.
Protector de pantallaNinguno, reloj digital, álbum de fotos o pantalla apagada.
CronómetroAdmite hasta 5 temporizadores simultáneos.
Banda de radio FM87.5–108 MHz (China) / 76–90 MHz (Japón).
Carga de bateríaRequiere cargador de salida 5V, 500–1000 mA. Se puede grabar audio mientras se carga.
Formato de músicaTodos los formatos de audio comunes; tasa de bits de 16 Kbps a 320 Kbps.
Formato de videoAMV/AVI, resolución 160×128 píxeles (requiere conversión previa).
Formato de imagenJPG, BMP, GIF.
Formato de texto (e-book)TXT.
Formato de letrasLRC.
Almacenamiento externoTarjeta Micro SD / MMC / SDHC.
Temperatura de operación0 °C a 45 °C.
Ecualizador (EQ)Normal, Rock, Punk, Hip Hop, Jazz, Clásico, Electrónico, Personalizado.

Reglas de uso obligatorias

  • No se debe abrir, reparar ni modificar el producto por cuenta propia.
  • No se debe sumergir el equipo ni sus accesorios en líquidos.
  • Si los botones táctiles se comportan de forma errática durante la carga o conexión USB, la regla es reiniciar el equipo.
  • El video debe convertirse con la herramienta oficial antes de poder reproducirse; archivos sin convertir no son compatibles.

Sección 3.1

Solución a problemas

ProblemaPosible causaSolución
El equipo no enciende Batería agotada Conecte el cargador (5V, 500–1000 mA) durante unos minutos y vuelva a intentar mantener presionado ⏻/🔒 por 3 segundos.
Los botones táctiles no responden o actúan de forma errática Interferencia al conectar USB/cargador, o botón cubierto Desconecte el cable, asegúrese de no cubrir el botón táctil y reinicie el reproductor.
No se reproduce el video El archivo no fue convertido al formato compatible Convierta el archivo con la herramienta de video incluida en el CD-ROM antes de copiarlo al equipo.
No se detecta la tarjeta de memoria Tarjeta no compatible o mal insertada Verifique que sea Micro SD/MMC/SDHC y que esté bien colocada en la ranura ②.
El Bluetooth no empareja Bluetooth apagado o PIN requerido Confirme que "Bluetooth Abierto/ON" esté activo y consulte al proveedor del otro dispositivo si pide código PIN.
El equipo no se reconoce en la computadora Cable o puerto USB defectuoso Use el cable USB incluido y conéctelo a un puerto USB2.0 de la computadora.

Sección 3.2

Catálogo de posibles errores o mensajes

Mensaje / EstadoSignificadoAcción recomendada
Botones "desordenados" (sin respuesta consistente) Conflicto de la superficie táctil durante carga o conexión Reiniciar el reproductor, según indica el fabricante.
Espacio en disco lleno El almacenamiento interno o la tarjeta externa alcanzó su capacidad máxima Revisar "Info → Espacio en disco" y eliminar archivos o formatear el dispositivo.

Sin señal / sin emisoras en radio FM Fuera del rango de frecuencia soportado Verificar que la frecuencia esté dentro de 87.5–108 MHz (China) o 76–90 MHz (Japón).
El equipo no carga Cargador con salida distinta a 5V / 500–1000 mA Usar el cargador o cable USB especificado en las características técnicas.

Sección 3.3

Glosario

TFT
Thin-Film Transistor: tecnología de pantalla usada en el display de 1.8 pulgadas del equipo.
EQ (Ecualizador)
Conjunto de ajustes de sonido predefinidos (Normal, Rock, Jazz, etc.) que modifican el tono de la reproducción.
FM (Frecuencia Modulada)
Banda de radio que el equipo puede sintonizar de forma manual o automática.
LRC
Formato de archivo de letras de canciones sincronizadas con la música.
Micro SD / MMC / SDHC
Tipos de tarjetas de memoria externa compatibles para ampliar el almacenamiento del equipo.
USB2.0
Estándar de conexión de alta velocidad usado para cargar el equipo y transferir archivos.
AMV / AVI
Formatos de video compatibles con el reproductor, tras ser convertidos con la herramienta incluida.
Power Bank
Batería externa portátil que puede usarse para cargar o extender el tiempo de uso del equipo.
Protector de pantalla
Función que activa un reloj digital, álbum de fotos o pantalla apagada tras un período de inactividad.
